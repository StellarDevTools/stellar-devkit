# Code of Conduct

Be respectful, constructive and welcoming. Discuss technical work on its merits. Harassment, threats, discrimination, doxxing and sharing another person's private information are not acceptable in this project's issues, pull requests or other project spaces.

Maintainers may edit or remove harmful content, restrict participation or close discussions that violate these expectations. Apply these rules consistently and preserve good-faith technical disagreement.

Report abusive public content through GitHub's report-abuse controls. Do not repost private information in an issue. Security vulnerabilities follow SECURITY.md. This is the project's own conduct policy; it does not claim adoption of a different policy or an unverified private contact address.
