# @stellar-devkit/ui

**Status**: Planned / Not Implemented

This package is reserved for shared UI components (buttons, forms, layout primitives) that could be reused across the web app and future interfaces.

Currently, it only exports a version string and is not used by any other package in the workspace.

## Planned Features

- Shared React components
- Common styling utilities
- Form validation helpers
- Stellar-specific UI widgets (address displays, amount formatters, etc.)

## Development

This package is included in the workspace build to ensure the infrastructure is working, but it provides no functional components yet. It can be safely excluded from production deployments.
